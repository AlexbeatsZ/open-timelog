# 时迹界面

面向需要随手记录学习、工作与生活的个人；首屏的任务是开始计时、补记和回顾当天。
采用灰蓝背景 `#f5f7f8`、白色纸面 `#ffffff`、深青绿 `#256f68`、墨色 `#263d43`、
学习蓝 `#357a9e`、消极玫瑰 `#b26360`。活动颜色兼作时间条与统计的编码。

正文使用本机 Segoe UI / Microsoft YaHei，不依赖在线字体。数字使用 Bahnschrift /
Consolas，以稳定宽度呈现计时。唯一的视觉重点是全天时间条：空白和已记录片段共同
呈现时间去向；计时圆环只是运行状态标识，不伪装成目标进度。

桌面为左侧导航、记录主列、右侧计时与目标。窄屏使用底部导航，按快速活动、计时、
记录、目标排序。所有页面应避免水平溢出，支持键盘焦点、原生表单与对话框。

空白状态必须告诉用户下一步做什么。初始提供活动但不伪造记录或统计。
操作使用明确动词：开始计时、结束并保存、补记、归档、恢复、导出。
进行中的计时不能被另一次开始静默覆盖。删除、放弃计时与兑换先在应用内确认。

备份先展示记录数量和时间；明确区分合并与完整恢复。操作失败展示具体原因；
读库失败保留原数据并提供恢复文件，不能显示一个貌似成功的空应用。

第一版仅浅色主题；不在界面许诺尚未实现的自动同步、后台通知或 Android 原生支持。
