- 存在 `cblite.dll`、`cblitedart.dll` 和 `cbl_flutter_ce_plugin.dll`；AOT 中可见

  **没有恢复数据库 schema、复制协议、认证协议或冲突处理语义。**
- 插件包括本地认证、通知、时区、语音、WebView、文件保存、应用链接等。
  插件存在不证明某个业务功能在当前版本可用。

  积极/消极、计时、积分、时间轴、流程、商品、经验等线索。
  `activityId`、`备份` 未命中指定编码，不能据此认定原版没有相关概念。
- 没有复制原版 `app.so`、图标、字体、地图网页、第三方插件二进制或其他资产。

## 实现选择

先把记录—回顾—反馈做成无需账户、服务端或网络的闭环；使用自己的稳定 JSON
schema，保留数据导出能力。后续原版兼容只能基于用户明确提供的脱敏导出样本，
先写只读转换器与验证工具，不直接操作原版数据库。

Electron 桌面壳的隔离与本地协议参考
[Electron 官方安全文档](https://www.electronjs.org/docs/latest/tutorial/security)；
渲染层不开放 Node API，不加载远端脚本。

## 下一阶段顺序

1. 在当前记录模型之上添加可拖动日视图、记录拆分与合并、倒计时。
2. 计划与可重复的流程步骤；明确跳过、暂停、中断恢复的行为。
3. 自托管同步：离线队列、删除标记、冲突可见、设备身份、备份恢复；另立设计文档。
4. Android 原生后台计时/通知与 APK 打包。PWA 适配通过桌面模拟验证不代表 Android 实机验收。
5. 脱敏原版导出兼容、用户自托管 Webhook、Obsidian 集成。
