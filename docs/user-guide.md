# 时迹 0.1.0 使用说明

[源码仓库](https://github.com/AlexbeatsZ/open-timelog) ·
[下载发行版](https://github.com/AlexbeatsZ/open-timelog/releases/tag/v0.1.0)

## Windows

下载 `Open-Timelog-0.1.0-Windows-x64.zip`，完整解压后运行
`Open Timelog.exe`。无需安装 Node，请保留程序文件夹中的全部文件。

默认提供学习、工作、阅读、运动、日常生活和无目的刷手机等活动，不预置虚构记录。
在「活动」页面可修改名称、颜色、性质和积分速率，或新建和归档活动。

## 记录和回顾

1. 点击活动卡片立即开始计时；也可以先填写描述，再点击「开始计时」。
2. 需要时暂停、继续或进入专注模式；完成后点击「结束并保存」。
3. 已经做过的事使用「补记时间」录入，填写活动、起止时间、描述和标签。
4. 「时间轴」支持切换日期、按性质筛选、搜索所有日期；「统计」显示近 7/30 天分布。
5. 「目标」按每日或每周设置活动时长，进度自动来自已保存记录。周一为每周起点。
6. 积极活动获得积分，消极活动消耗积分；在「奖励」创建并兑换自己的奖励。

计时包含关闭程序、系统睡眠和锁屏期间的经过时间；不包含暂停期间。
系统时间向前调整也会增加时长，需要时保存后手工修正记录。系统时间倒退时程序
拒绝保存并保留计时。日期归属按设备当前本地时区计算。

## 备份与迁移

「数据与设置」提供 JSON 完整备份、全部有效记录 CSV、选定日期 Markdown 回顾。
定期独立保留 JSON。复制程序目录不能迁移个人数据；网页、不同浏览器和桌面端的数据独立。

导入只接受时迹 v1 JSON，先预览内容，再选择：

- **合并**：同 ID 保留较新版本，归档和删除标记一并参与；进行中的计时须先保存。
- **完整恢复**：以备份替换本机全部状态，支持恢复进行中的计时。

执行前程序会先下载本机备份。CSV 与 Markdown 用于分析和阅读，不能无损恢复所有状态。
数据读取失败时不要清除存储；保留原始目录，并使用程序提供的恢复文件导出。

## 网页 / PWA

下载 `Open-Timelog-0.1.0-web.zip`，将解压后的内容部署到 HTTPS 静态站点；
本机可用 localhost。首次在线打开并完成缓存后支持离线重开，也可在支持的浏览器
中安装为 PWA。直接双击 HTML 文件不属于支持的运行方式。

## 更新和反馈

更新前导出 JSON，关闭应用后将新版解压到独立程序目录。启动后检查记录和目标；
需要时从备份恢复。当前仅有 v0.1.0，尚无跨版本迁移验收，不能手改未来备份格式版本
来绕过导入校验。

如遇问题，在 [Issues](https://github.com/AlexbeatsZ/open-timelog/issues) 提供平台、
版本、操作步骤和报错。只附脱敏样本，不公开个人完整时间记录或恢复文件。

定位/NFC 和 Android 原生 APK。移动布局只经过桌面浏览器窄屏模拟，未做 Android 实机验收。
