# 时迹 0.2 使用说明

打开后只有四个主面板：时间线、计时、目标、分析。

- 时间线最新在上。空闲也显示卡片，点击后预填完整时段，选择活动并保存即可补记。
  记录下方的“填满上方/下方空闲”分别延长结束或提前开始；确认后才修改。
  菜单中可编辑或删除；设置的“最近删除”可以恢复。
- 计时面板点活动立即开始，进入计时详情。可填写描述、暂停、继续、专注；结束并保存
  自动回到今天的时间线。选择“从上条记录结束开始”可以把最近空档计入本次计时。
  关闭应用不会自动暂停；不希望计入休息时间时先暂停。
- 目标面板建立每日/每周活动时长目标，进度自动按已保存记录计算。
- 分析面板查看当日/近 7/30 天的时长、积分和活动统计；点击日期柱跳到那一天。
  积分由每条记录时长和当时速率计算，目前没有商店。

设置在桌面左下角，手机右上角。颜色模式可跟随系统，也可固定浅色或暗色。
活动名称、性质、颜色和积分速率在“计时 → 管理活动”修改，只影响新计时/新记录。

定期在设置导出 JSON。迁移到另一台设备时导入预览，选择合并或完整恢复。
执行前会先保存本机备份；Android 取消文件保存就取消导入。CSV/Markdown 便于阅读分析，
完整恢复请使用 JSON。当前没有自动同步，原版 UpTimer 备份不能直接导入。

Windows 保留解压后的全部文件；Mac 包当前未做 Apple 公证；Android 支持 7.0+。
网页需部署到 HTTPS 或 localhost，首次在线缓存后可离线使用。
手机当前提供 Android APK 和网页/PWA，尚无 iOS 原生安装包。

桌面版可由本机 AI 通过 REST API 操作，见 docs/api.md；不要把 api.json 凭据发进聊天或仓库。
